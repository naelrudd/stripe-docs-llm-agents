# Identity

Verify government-issued IDs, match documents to selfies, and validate SSNs to prevent fraud.

Use [Stripe Identity](https://stripe.com/identity) to confirm the identity of global users to prevent fraud, streamline risk operations, and increase trust and safety. [Learn about the verification use cases and business locations supported by Stripe Identity](https://docs.stripe.com/identity/use-cases.md).

Stripe Identity allows you to:

- Verify the authenticity of government-issued ID documents from more than 120 countries
- Capture government-issued photo IDs with a conversion-optimized verification flow
- Match government-issued photo IDs with selfies, and validate Social Security numbers (SSNs)
- Access collected images, and extracted data from government-issued ID documents

## Get started 

[Sign up](https://dashboard.stripe.com/identity/application): Activate Identity in the Dashboard.

[Verify your users’ identity documents](https://docs.stripe.com/identity/verify-identity-documents.md): Begin by creating sessions and collecting identity documents.

[Handle verification outcomes](https://docs.stripe.com/identity/handle-verification-outcomes.md): Listen for verification outcomes so your integration can automatically trigger reactions.

[Create re-usable configuration](https://docs.stripe.com/identity/verification-flows.md): Use verification flows to create re-usable configuration and manage identity verification in the Dashboard.

## More verification checks 

[Verification checks](https://docs.stripe.com/identity/verification-checks.md): Learn about all the different verification checks supported by Stripe Identity.

[Adding selfie checks](https://docs.stripe.com/identity/verification-checks.md?type=selfie#adding-selfie-checks): Add face similarity checks to prevent fraudsters from using stolen documents.

[Additional verifications for Connect](https://docs.stripe.com/connect/additional-verifications.md): Collect additional identity verification as part of Connect onboarding.
